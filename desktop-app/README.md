# برنامج الكيف الأصلي لويندوز

برنامج مكتبي لويندوز يفتح نظام الكيف الأصلي في نافذة مستقلة، بدون متصفح. مخصص للمحاسب والإدارة والمستودع.

## المزايا
- برنامج مستقل بشعار الكيف الأصلي، وله اختصار على سطح المكتب وقائمة ابدأ.
- **عند أول تشغيل** يطلب عنوان الخادم ويتحقق من الاتصال، ويمكن تغيير العنوان لاحقاً من **ملف ← تغيير عنوان الخادم**.
- **قائمة عربية:**
  - **ملف:** الصفحة الرئيسية، إعادة التحميل (F5)، الطباعة (Ctrl+P).
  - **عرض:** التكبير والتصغير، وملء الشاشة (F11).
  - **مساعدة:** البحث عن تحديثات.
- التقارير والملفات التي يفتحها النظام تظهر في نوافذ البرنامج، والروابط الخارجية تُفتح في المتصفح.
- عند انقطاع الاتصال تظهر صفحة واضحة، ويعيد البرنامج المحاولة تلقائياً كل 30 ثانية.
- يتذكر حجم النافذة ومستوى التكبير.
- **التحديث التلقائي:** عند صدور إصدار جديد يحمّله البرنامج ويثبّته عند الإغلاق.
- **الأمان:**
  - صفحات الخادم معزولة، ولا تصل إلى الجهاز ولا إلى إعدادات البرنامج.
  - الكاميرا (لقراءة الباركود) والموقع والإشعارات مسموحة لخادم النظام فقط.

## التحميل والتثبيت
- **بناء تجريبي:** صفحة المستودع ← **Actions** ← **Desktop app** ← آخر تشغيل ← **Artifacts** ← `alkaif-desktop-setup`.
- **إصدار رسمي:** أنشئ وسماً مثل `desktop-v1.0.0`، فيُنشأ **Release** فيه ملف التثبيت `AlKaif-Setup-1.0.0.exe`. البرامج المثبّتة تتحدث منه تلقائياً.
- **تحذير ويندوز عند التثبيت:** قد يظهر تحذير "Windows protected your PC" لأن البرنامج غير موقّع بشهادة توقيع كود. اضغط **More info ← Run anyway**. لإزالة التحذير نهائياً يلزم شراء شهادة توقيع كود (Code Signing) وإضافتها إلى البناء.

## للمطورين
```
npm install
npm start          # تشغيل البرنامج
npm test           # اختبارات الإعدادات
npm run dist       # بناء ملف التثبيت (على ويندوز)
xvfb-run node test-e2e/run.js shots   # اختبار شامل على لينكس (يحتاج playwright)
```
